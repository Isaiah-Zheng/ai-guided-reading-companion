# Local dictionary

759,781 headword/form records derived from ECDICT (skywind3000), MIT license.
Source: https://github.com/skywind3000/ECDICT/blob/master/ecdict.csv
Includes alphabetic words/phrases and inflected-form aliases, compacted definitions,
IPA and frequency indicators. Text is general dictionary information, not contextual
AI explanation. Preserve LICENSE.txt when redistributing. Loaded in letter buckets
inside the extension; no external dictionary API is contacted.
